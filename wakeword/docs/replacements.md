# Section 2 — Dataset replacement strategy

Every asset that touches a **production** model must be on the license allowlist
(CC0 / CC-BY / MIT / Apache / BSD / Public Domain). The pipeline enforces this in
code via [`scripts/verify_licenses.py`](../scripts/verify_licenses.py) — see
[`licensing.md`](licensing.md).

## Replacement matrix

| Role | Notebook default (avoid) | Replacement | License | Notes |
|---|---|---|---|---|
| Bulk negative **features** | ACAV100M `.npy` | **LibriSpeech** → self-precomputed `.npy` | CC-BY-4.0 | Generated by `precompute_features.py` (step 4). |
| FP **validation features** | `validation_set_features.npy` | **MUSAN** + **LibriSpeech** dev → self-built | CC-BY-4.0 | Build your own ~11 h held-out set. |
| Background noise | AudioSet sample | **MUSAN/noise** + **FSD50K** (BY/CC0 subset) | CC-BY-4.0 | Filter FSD50K per-clip to BY/CC0. |
| Music | FMA `small` (unfiltered) | FMA commercial cut, e.g. `benjamin-paine/free-music-archive-commercial-16khz-full` | CC0/CC-BY/PD | hey-buddy pre-filtered this. |
| Room impulse responses | MIT RIR (32 kHz) | `benjamin-paine/mit-impulse-response-survey-16khz` | CC-BY | Already 16 kHz — skips resample. |
| Positive speech | — | **Piper TTS** synthetic | MIT/Apache | No real-voice data needed for positives. |
| Feature extractor / mel | openWakeWord release | (unchanged) | Apache-2.0 | Keep. |

## Reference: commercially-cleared dataset curation

[`benjamin-paine/hey-buddy`](https://huggingface.co/benjamin-paine/hey-buddy) is the
best public reference for *commercial-safe* augmentation sets, even though its runtime
is not openWakeWord-compatible. Mine its **dataset choices**, not its model format.

## Provenance tracking

For every downloaded or generated asset the pipeline writes a sidecar manifest
(`<asset>.license.json`) conforming to
[`datasets/licenses/manifest.schema.json`](../datasets/licenses/manifest.schema.json):

```json
{
  "asset": "musan/noise/free-sound/noise-free-sound-0001.wav",
  "dataset": "MUSAN",
  "dataset_version": "v1.0 (2015-12-15)",
  "source_url": "https://www.openslr.org/17/",
  "license": "CC-BY-4.0",
  "license_url": "https://creativecommons.org/licenses/by/4.0/",
  "commercial_use": true,
  "attribution": "MUSAN: A Music, Speech, and Noise Corpus. Snyder, Chen, Povey (2015).",
  "retrieved": "2026-06-16",
  "sha256": "<hex>"
}
```

A dataset-level roll-up lives in [`LICENSES.md`](../LICENSES.md), and CC-BY
attributions are compiled into `ATTRIBUTION.generated.md` (surfaced in Qube's
**Settings → Help → Wakeword models**). All checksums + versions are pinned in
`datasets/licenses/manifest.lock.json` so a future clone reproduces identical inputs
or fails loudly.
