Get started

Windows: winget install -e --id dagaza.Qube or GitHub Releases. macOS: download the .dmg from Releases. Developers: see install from source.

Help ships inside the app — open Library → Qube or type @[tool:help] in chat.

How Qube compares

LM Studio runs models brilliantly. SillyTavern masters prompts and lorebooks. Odysseus bundles a whole self-hosted workspace. Qube targets a native desktop assistant: routing to your Library, curated memory, or live institutional sources — with @ composer tools, numbered citations, and a Memory Manager you can edit.
