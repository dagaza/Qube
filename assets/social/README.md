# Social preview assets

GitHub and link previews for the Qube repository.

## Files

| File | Size | Use |
|------|------|-----|
| [`qube-social-preview.png`](qube-social-preview.png) | 1200×630 (intended) | GitHub **Social preview**, Open Graph |

## Set GitHub social preview

1. Open **GitHub → dagaza/Qube → Settings → General**
2. Under **Social preview**, click **Edit**
3. Upload `assets/social/qube-social-preview.png`

Links to the repo will then show the card on Twitter/X, Slack, Discord, etc.

## Regenerate before launch

If branding or tagline changes, regenerate the image and re-upload. See [launch documentation guidelines](../docs/launch_documentation_guidelines.md) Phase 4.

**Note:** The landing page at [`docs/index.html`](../docs/index.html) references this file for `og:image` when GitHub Pages is enabled (`https://dagaza.github.io/Qube/assets/social/qube-social-preview.png`).
