# Help

## Common questions

- How do I replay a guided tour?
- Where is the composer `@` mention guide?
- How do I reset help and onboarding guidance?
- Where are custom sources and composer tools configured?
- How do I uninstall Qube?
- How do I update Qube to a new version?

## What it is

**Help** settings connect you to Qube’s guidance layer: built-in documentation, **guided tours**, the **Open @ Composer Guide** dialog, shortcuts into Knowledge customisation pages, and software update checks.

This page does not host the full help corpus—that lives under **Library → Qube** via **Open Qube documentation**. Resetting tour completion is **not** a button here; use the composer command **Reset Help & Guidance** (see [Composer commands reference](../../reference/composer-commands.md)).

## Where to find it

Open **Settings → Help** (settings section `help`). Press **?** for the guided tour (`settings.help`).

## Also called

help and guidance, guided tours, onboarding reset, composer guide, HELP & GUIDANCE

## How to…

1. **Open built-in docs** — Click **Open Qube documentation** to jump to **Library → Qube**.
2. **Replay Local LLM setup** — Click **Replay Local LLM Setup Tour** under **Guided tours**.
3. **Open the composer guide** — Click **Open @ Composer Guide** to learn tools, skills, and commands.
4. **Jump to customisation pages** — Use **Open Custom sources** or **Open My knowledge** to open the matching **Knowledge** subsections.
5. **Reset guidance** — In **Conversations**, run **Reset Help & Guidance** from the composer command palette (not on this settings page).
6. **Uninstall Qube** — Scroll to **Uninstall Qube** for Windows, macOS, and Linux removal steps. On supported packaged installs (macOS `.app`, Linux `.deb`), use the quick-uninstall buttons. See [Uninstall Qube](../../workflows/uninstall-qube.md) in Library → Qube.
7. **Update Qube** — Open **Software updates** on this page and click **Check for updates**, or download a newer build from [GitHub Releases](https://github.com/dagaza/Qube/releases). See [Update Qube](../../workflows/update-qube.md).
