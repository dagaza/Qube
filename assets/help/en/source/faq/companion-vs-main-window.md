# Companion vs main window

## Common questions

- What is the Desktop Companion for?
- Do I need both the companion and the main Qube window?
- Can I use chat only from the floating orb?

## What it is

The **main window** (Conversations, Library, Settings, Model Manager) is the full Qube application—history, attachments, browsing, and configuration. The **Desktop Companion** is a lightweight always-on-top orb for quick voice turns and status at a glance without raising the full UI.

Use the companion for fast interactions; use the main window for long threads, Library work, and detailed settings.

## Where to find it

Open the main window from the taskbar or dock. Toggle the companion in **Settings → Desktop Companion**.

## Also called

orb vs main app, floating companion vs conversations, overlay vs full window, quick voice vs full chat

## How to…

1. Keep the **main window** open when you need full composer features, `@` attachments, or Library preview.
2. Enable the **companion** when you want hands-free or glanceable access from other apps.
3. Configure **Hide during fullscreen apps** if the orb should not cover games or slides.
4. Switch to the main window when the companion’s minimal UI is not enough for your task.
