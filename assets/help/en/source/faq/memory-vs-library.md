# Memory vs Library

## Common questions

- What is the difference between Memory and Library?
- Should I store notes in Memory or upload them to Library?
- Does Library search use Memory entries?

## What it is

**Library** stores your documents—files you import, chunk, and search with **`@[tool:library]`**. **Memory** stores short distilled facts about you and your preferences for long-term recall across conversations. They use different pipelines: Library is document RAG; Memory is structured personal context.

Put durable reference material in Library. Put preferences, relationships, and standing facts in Memory (or let automation capture them there).

## Where to find it

Browse files in **Library → Main** and facts in **Memory Manager**. Settings split across **Settings → Knowledge** (Library search) and **Settings → Memory** (automation).

## Also called

memory versus documents, RAG vs long-term memory, library or memory, where to save notes

## How to…

1. **Use Library** for PDFs, manuals, project folders, and anything you want passage-level citations from.
2. **Use Memory** for “always remember I prefer metric units” or similar standing preferences.
3. Attach **`@[tool:library]`** when you need document evidence; rely on Memory context for personal facts without re-uploading each chat.
4. If recall fails, check the right store—see troubleshooting guides for each path.
