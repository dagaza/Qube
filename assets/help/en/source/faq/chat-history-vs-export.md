# Chat history vs export

## Common questions

- How long does Qube keep my conversations?
- Can I save a chat outside Qube?
- What's the difference between Copy conversation and Download conversation?

## What it is

Every **Conversations** thread is stored locally in Qube's database for that installation. **Copy conversation** puts the full transcript on the clipboard; **Download conversation** writes a Markdown file you can archive elsewhere.

Exports are snapshots — editing an exported file does not change the in-app thread. Long-term **memory** entries are separate from exported chat files.

## Where to find it

Open a conversation in **Conversations**, then use **Copy conversation** or **Download conversation** in the reading toolbar (top of the transcript area).

## Also called

export chat, save conversation, backup chats, download transcript, copy thread, archive conversation

## How to…

1. **Copy for quick sharing** — Click **Copy conversation** and paste into email or notes.
2. **Save a Markdown archive** — Click **Download conversation** and choose where to store the `.md` file.
3. **Find the thread again** — Use the **Conversations** sidebar search or folder filters; exports are not indexed automatically.
4. **Preserve facts separately** — For durable recall across sessions, rely on **Memory Manager** or explicit “remember this” requests — not exports alone.
