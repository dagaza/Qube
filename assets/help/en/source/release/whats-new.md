# What's new in Qube Help (v1.0.25)

## Common questions

- What changed in the help documentation?
- How do I search built-in help from chat?
- Where is the full documentation index?

## What it is

This page summarizes the **v English help corpus** shipped with Qube. The corpus lives in **Library → Qube** and powers **`@[tool:help]`** in **Conversations**.

**v1.0.25** documents **per-import precision indexing** — the **Choose indexing mode** dialog on Library upload, the sidebar **gem badge** for precision-indexed documents, and updated `@help` answers.

**v1.0.24** added **[Library Pro depth](../faq/library-pro-depth.md)** — precision ingest, precision retrieval, Pro license import, and canonical `@help` answers for **Settings → Knowledge** toggles.

## Where to find it

Open **Library → Qube → release/whats-new.md**, or attach **`@[tool:help]`** and ask about help features. The router index is **[Qube Help](../00-index.md)**.
