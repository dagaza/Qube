# License

## Common questions

- How do I import a Qube Pro license?
- What does a Pro license unlock for Library?
- Where is the cached license stored?
- How do I remove a license?

## What it is

**License** settings import a signed `.qube-license` file that unlocks paid edition capabilities. For **Library**, this includes **Precision indexing** in the import dialog and **Library Pro depth** toggles under **Settings → Knowledge**. Licenses are cached locally; nothing prompts you on startup.

Use **Remove cached license** to drop the local copy — Pro toggles turn off on next sync and **Precision indexing** is disabled in the import dialog. See [Library Pro depth FAQ](../../faq/library-pro-depth.md).

## Where to find it

Open **Settings → License** (settings section `license`). Press **?** for the guided tour (`settings.license`).

Legacy deep links to **Settings → Advanced → License** redirect here.

## Also called

Pro license, qube-license, license import

## How to…

1. **Import a Pro license** — Click **Import license file** and select your `.qube-license` or JSON file.
2. **Enable Library Pro depth** — After import, open **Settings → Knowledge → Library Pro depth**. See [Enable Library Pro depth workflow](../../workflows/enable-library-pro-depth.md).
3. **Remove a cached license** — Click **Remove cached license** to delete the local copy.
