# License

## Common questions

- How do I activate a Qube Pro license key?
- How do I import a Qube Pro license file?
- What does a Pro license unlock for Library?
- Where is the cached license stored?
- How do I remove a license?

## What it is

**License** settings activate a signed Qube license from a **QUBE1 serial key** (paste from email) or a **`.qube-license` file**. Paid edition capabilities include **Library Pro depth** and **Precision indexing** in the import dialog. Licenses are cached locally; nothing prompts you on startup.

Use **Remove cached license** to drop the local copy — Pro toggles turn off on next sync and **Precision indexing** is disabled in the import dialog. See [Library Pro depth FAQ](../../faq/library-pro-depth.md).

## Where to find it

Open **Settings → License** (settings section `license`). Press **?** for the guided tour (`settings.license`).

Legacy deep links to **Settings → Advanced → License** redirect here.

## Also called

Pro license, qube-license, license key, license import, QUBE1 key

## How to…

1. **Activate a license key** — Paste your **QUBE1** key from the purchase email and click **Activate license key**. Spaces and dashes are ignored.
2. **Import a license file** — Click **Import license file** and select your `.qube-license` or JSON file.
3. **Enable Library Pro depth** — After activation, open **Settings → Knowledge → Library Pro depth**. See [Enable Library Pro depth workflow](../../workflows/enable-library-pro-depth.md).
4. **Remove a cached license** — Click **Remove cached license** to delete the local copy.
