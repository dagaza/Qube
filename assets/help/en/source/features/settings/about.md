# About

## Common questions

- What version of Qube am I running?
- How do I check for updates?
- Where is the Qube website?

## What it is

**About** settings show your installed Qube version, link to the project website, and let you check GitHub Releases for newer builds.

## Where to find it

Open **Settings → About** (settings section `about`). Press **?** for the guided tour (`settings.about`).

## Also called

about qube, app version, software updates, check for updates, ABOUT

## How to…

1. **See your version** — The **About Qube** card shows the installed release (for example `1.2.9`).
2. **Open the website** — Click **Open Qube website** to visit [qubeapp.eu](https://www.qubeapp.eu).
3. **Check for updates** — Under **Software updates**, click **Check for updates**. Qube compares your version with the latest GitHub Release and opens the matching download when a newer build is available. See [Update Qube](../../workflows/update-qube.md).
