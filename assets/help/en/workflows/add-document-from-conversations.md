# Add a document from Conversations

## Common questions

- How do I upload a PDF while chatting?
- Can I drag a file into the chat?
- Do uploads still go to Library?

## What it is

You can ingest documents **without leaving Conversations**. Files are indexed into **Library → Main** (same pipeline as **+ Ingest New Document**), then Qube attaches **`@[file:…]`** to your **current** chat so the next message can scope retrieval to that file.

## Where to find it

**Conversations** composer:

- **Upload** button (next to **@**)
- **@ → Files → Upload new document…**
- **Drag and drop** onto the message area or composer

## How to…

1. Open or continue a conversation.
2. Upload via the button, **@** palette, or drag-and-drop (`.txt`, `.md`, `.pdf`, `.epub`).
3. Choose **Normal** or **Precision** indexing when prompted (same as Library).
4. Wait for the progress banner; a file chip appears on the composer when indexing finishes.
5. Type your question and send (file attachments need a message body). The **file chip stays** for follow-up questions in the same chat until you remove it; Qube remembers it for that conversation when you switch chats and come back.
